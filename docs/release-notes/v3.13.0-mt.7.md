# v3.13.0-mt.7

Tiger Studio can wake the scale's screen from the computer, and a scale left on the start menu
no longer shows as offline.

## Added

- **Wake the screen from Tiger Studio.** The "Wake up" button on the scale's card in the Tiger Studio
  fork lights the screen of a sleeping scale. It never presses anything: a screen that
  is already on only restarts its sleep countdown. The live view and the screenshot use it too,
  instead of a tap in the middle of the screen, which could press a button. Needs the LAN live
  view switched on (Settings > LAN).

## Fixed

- **A scale on the start menu or in a tool stays online in Studio.** It used to send one heartbeat
  when its screen went dark and then nothing, so Studio showed it offline while it was switched on
  and connected.
- **Heartbeats are no longer refused after an hour of sleep.** The scale renews its sign-in before
  each heartbeat, so a screen left asleep for hours keeps reporting.
- **After a restart, the start menu no longer leaves the scale unreachable.** The web pages, the
  live view and the cloud connection used to wait until a tool was opened; they now start on their
  own a few seconds after boot.

## Known issues

- Free memory gets tight after some use (about 35 KB in one block, where a secure connection needs
  about 32 KB). If heartbeats start failing after several hours, restart the scale. This was already
  the case in mt.6 and is being investigated.
- A scale on the official firmware does not see this release in Settings > Update: install it once
  over USB from the installer page; updates then come from this fork.

## Updating

Over the air from **Settings > Update** on a scale already running Tiger Multi-tools (the start
menu also offers it), or from the installer page (https://juditech3d.github.io/Tiger-Scale-V3/)
over USB. Answer no when asked to erase the device: that keeps your Wi-Fi credentials, TigerTag
session and calibration.
