# v3.13.0-mt.4

The scale now tells you about an update wherever you are, and the RFID Auto calibration also
chooses the sensitivity.

## Added

- **Update notification from the start menu.** The scale checks for an update 20 s after boot
  and every 6 hours from the start menu and every tool too, not only from the Tiger Scale screen,
  and shows the update card on the start menu as it does on the Tiger Scale screen. A sleeping
  screen shows it once woken; a tool shows it on the way back to the menu.
- **Skip this version.** The update card has three answers: *Skip* (that version is not offered
  again, the next one will be; Settings > Update still installs it), *Later* (asked again in
  24 hours) and *Yes*.
- **RFID Auto calibration sets the sensitivity.** After choosing the power level at the default
  38 dB, Auto measures the four sensitivities at that level and keeps another one only if it
  clearly reads better. The result shows both, e.g. "Best level 7/15 - 43 dB".

## Known issues

- A scale on v3.13.0-mt.3 or older shows the update card only on the Tiger Scale screen: install
  this release from Settings > Update. From this release on, the start menu shows it too.
- A scale on the official firmware does not see this release in Settings > Update: install it once
  over USB from the installer page; updates then come from this fork.

## Updating

Over the air from **Settings > Update** on a scale already running Tiger Multi-tools, or from the
installer page (https://juditech3d.github.io/Tiger-Scale-V3/) over USB. Answer no when asked to
erase the device: that keeps your Wi-Fi credentials, TigerTag session and calibration.
