# v3.13.0-mt.3

The screen now sleeps in the start menu and every tool, and the RFID readers get a sensitivity
setting for chips that are hard to read.

## Added

- **Screen sleep in every tool.** The start menu, the tool picker, Parcel scale, Calibration &
  test, Heat press memo and TigerPOD now turn the screen off after the delay set in Settings >
  Screen, like the Tiger Scale screen already did, to avoid burn-in. The tool keeps running with
  the screen off, and the first touch only wakes it: it presses nothing.
  - Parcel scale and Calibration & test also wake when the weight moves by more than 10 g.
  - TigerPOD keeps answering Tiger Studio while dark, and wakes when a chip is put down.
  - Heat press memo never sleeps while its timer counts or its end alarm rings.
- **RFID sensitivity.** Settings > RFID has a new *Sensitivity* stepper beside the power level:
  the readers' receive gain, 33, 38, 43 or 48 dB. 38 dB is the value every reader ran at before
  and stays the default; any other value is shown in orange. Raising it may help a chip that is
  small or sits deep in the spool hub; if the readings get unstable, go back to 38 dB.

## Known issues

- A scale on the official firmware does not see this release in Settings > Update: install it once
  over USB from the installer page; updates then come from this fork.

## Updating

Over the air from **Settings > Update** on a scale already running Tiger Multi-tools, or from the
installer page (https://juditech3d.github.io/Tiger-Scale-V3/) over USB. Answer no when asked to
erase the device: that keeps your Wi-Fi credentials, TigerTag session and calibration.
